# 单目图像平面尺寸测量工具

基于 Python 和 OpenCV 的单目视觉尺寸测量项目。通过摄像头获取图像，使用已知真实尺寸的参考物进行像素比例标定，再通过图像预处理、轮廓检测和像素尺寸换算，实现同一平面内物体的长宽测量。

## 1. 项目简介

本项目主要用于学习和实践 OpenCV 图像处理、摄像头调用、相机标定及视觉尺寸测量的基本流程。

主要处理流程：

1. 打开摄像头并获取实时图像。
2. 对图像进行灰度化、滤波和二值化处理。
3. 检测图像中的物体轮廓。
4. 获取物体的外接矩形及像素尺寸。
5. 根据标定比例换算物体的实际尺寸。
6. 在图像上绘制检测框和测量结果。
7. 将测量记录保存到 CSV 文件。

## 2. 功能特性

- **摄像头采集**：支持指定摄像头设备索引、分辨率和帧率。
- **像素比例标定**：通过已知真实尺寸的参考物计算像素与毫米的比例，并记录参考物信息、标定时间和画面分辨率。
- **交互式标定**：独立标定工具或主程序内按 `C`/`R` 随时标定，按 `X` 清除标定参数。
- **分辨率校验**：测量时自动校验画面分辨率是否与标定时一致，不一致时给出警告。
- **未标定模式**：无有效标定时程序仍可运行，只显示像素尺寸，不输出看似有效的真实尺寸。
- **图像预处理**：灰度化、高斯模糊，支持 Otsu / 自适应阈值 / Canny 边缘检测（含形态学闭运算）三种前景提取方式，可通过命令行参数切换。
- **调试视图**：按 `P` 循环显示灰度图、边缘/二值图，便于排查阈值问题。
- **轮廓检测**：提取物体轮廓并根据面积过滤检测结果。
- **最小外接旋转矩形**：使用 `minAreaRect` 获取物体的旋转包围框，物体倾斜时也能测出真实长宽。
- **帧间平滑**：对检测结果做指数平滑（EMA），减少手持测量时的数值抖动。
- **尺寸计算**：将检测到的像素尺寸转换为毫米，并区分显示旋转矩形面积与轮廓面积。
- **手动框选测量**：按 `M` 冻结画面手动框选待测物体进行测量。
- **结果可视化**：绘制旋转矩形框、中心点、编号、长宽、面积，以及标定状态和测量模式。
- **测量记录**：用户确认后写入 CSV（含测量模式、像素比例、矩形/轮廓面积）。
- **截图保存**：按 `S` 保存带标注的测量截图。
- **单元测试**：`tests/` 目录提供核心模块的单元测试。

> 界面文字使用英文，因为 OpenCV 自带字体无法渲染中文；完整的中文提示（如"被测物体必须与标定参考物处于同一平面，否则测量结果可能存在误差"）在终端输出。

## 6. 摄像头测试

默认使用设备索引 `0`。

运行主程序：

```bash
python main.py --index 0
```

常用命令行参数：

| 参数 | 说明 | 默认值 |
|---|---|---|
| `--index` | 摄像头设备索引 | 0 |
| `--width` / `--height` | 请求的分辨率 | 640 / 480 |
| `--fps` | 请求的帧率 | 30 |
| `--calibration` | 标定文件路径 | config/calibration.yaml |
| `--min-area` | 最小轮廓面积（px²） | 1000 |

## 7. 交互式标定

### 7.1 启动标定工具

```bash
python -m src.calibration_tool --index 0
```

### 7.2 操作步骤

1. 等待摄像头画面出现。
2. 按 `c` 冻结当前画面。
3. 在弹出的图像中框选参考物，按 Enter 或空格确认。
4. 选择框选区域的宽度或高度。
5. 输入对应边的真实长度，单位为毫米。
6. 检查计算出的像素比例。
7. 输入 `y` 确认保存。

按 `q` 或 `Esc` 可以退出实时标定画面。

**注意：** 默认保存路径为 `config/calibration.yaml`。确认标定结果后再保存，以免覆盖已有的有效标定参数。

### 7.3 标定文件格式

`config/calibration.yaml` 示例：

```yaml
version: 1
method: reference_object
pixels_per_mm: 0.8451612903225807
unit: mm
reference:
  real_length_mm: 100.0
  pixel_length: 118.35
  edge: 宽度
resolution: [640, 480]
calibrated_at: '2026-10-20T15:30:00+08:00'
```

其中：

- `version`：配置格式版本。
- `method`：标定方法（`reference_object` 为已知尺寸参考物标定，区别于相机内参标定）。
- `pixels_per_mm`：每毫米对应的像素数。
- `unit`：测量单位。
- `reference`：参考物信息（真实长度、像素长度、参考边）。
- `resolution`：标定时的画面分辨率（宽, 高）。测量时会自动校验，分辨率不一致时测量结果不可信。
- `calibrated_at`：标定时间（ISO 8601）。

示例中的比例仅用于展示配置格式，实际测量时应使用现场标定得到的数值。

## 8. 测量原理

当前基础版本使用固定像素比例进行尺寸换算。

设：

- \(L_{px}\)：物体在图像中的像素长度。
- \(k\)：标定得到的像素比例，单位为 px/mm。
- \(L_{mm}\)：物体的实际长度，单位为 mm。

则：

\[
L_{mm}=\frac{L_{px}}{k}
\]

像素比例由参考物的已知真实长度计算：

\[
k=\frac{L_{px,\mathrm{ref}}}{L_{mm,\mathrm{ref}}}
\]

其中，\(L_{px,\mathrm{ref}}\) 为参考边的像素长度，\(L_{mm,\mathrm{ref}}\) 为该边的真实长度。

### 测量条件

该方法适用于同一测量平面内的基础尺寸测量。为了获得可靠结果：

- 标定物与待测物应位于同一平面。
- 标定后应固定摄像头位置和焦距。
- 摄像头应尽量垂直于测量平面。
- 参考物与待测物的对应边应正确选择。
- 应保证光照充足、物体轮廓清晰。
- 对于明显的镜头畸变、透视变形或倾斜平面，应进一步进行相机标定、畸变校正或透视变换。

**本项目当前的固定比例法不能直接保证任意空间位置下的物体尺寸准确。** 物体距离相机发生变化时，图像中的像素尺寸也会变化。


当前主程序提供的快捷键：

| 按键 | 功能 |
|---|---|
| `q` / `Esc` | 退出程序 |
| `C` / `R` | 标定 / 重新标定（框选参考物） |
| `X` | 清除标定参数，进入未标定模式 |
| `M` | 冻结画面，手动框选物体测量 |

## 10. 测量结果保存

测量记录保存至：

```text
data/measurements.csv
```

记录文件用于保存检测到的物体及对应测量结果，字段包括：时间戳、物体编号、测量模式（auto 自动检测 / manual 手动框选）、像素尺寸、毫米尺寸、长短边、旋转矩形面积（rect_area_mm2）、轮廓面积（contour_area_mm2）和标定比例（pixels_per_mm）。注意旋转矩形面积是长宽乘积，与不规则物体的真实轮廓面积不同。记录仅在用户按 `D`（自动）或 `M`（手动）确认后写入，不会每帧重复写入。

建议使用已知尺寸的矩形物体进行测试，记录测量值与真实值之间的差异。

误差率计算公式：

\[
E=\frac{|L_{\mathrm{measured}}-L_{\mathrm{true}}|}
{L_{\mathrm{true}}}\times100\%
\]

其中：

- \(L_{\mathrm{measured}}\)：程序测量值。
- \(L_{\mathrm{true}}\)：物体真实尺寸。
- \(E\)：相对误差率。

## 11. 常见问题

### 11.1 摄像头无法打开

- 检查摄像头连接。
- 确认摄像头没有被其他程序占用。
- 尝试使用其他设备索引，例如 `--index 1`。

### 11.2 测量值偏差较大

- 检查标定物真实尺寸是否输入正确。
- 确认框选的是完整参考边。
- 确认待测物与标定物处于同一平面。
- 检查轮廓框是否包含背景或遗漏物体边缘。
- 检查摄像头是否倾斜，以及镜头畸变是否明显。

### 11.3 图像中没有检测到物体

- 调整光照，避免强反光和明显阴影。
- 按 `p` 检查二值化效果。
- 检查 `src/image_processor.py` 的阈值处理参数。
- 检查 `src/contour_detector.py` 的最小轮廓面积等过滤条件。

### 11.4 图形界面无法正常显示

在 Linux 桌面环境中运行程序，并确认 OpenCV GUI 依赖正常安装。通过 `pip` 安装的 `opencv-python` 通常提供窗口显示功能；不要同时安装多个互相冲突的 OpenCV Python 包。
